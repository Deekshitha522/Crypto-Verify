# 🔐 CryptoVerify

**Secure Digital Document Verification Platform using SHA-256 Hashing, RSA Digital Signatures, QR Code Verification, and Flask.**

## 📌 Overview

CryptoVerify is a Flask-based web application that enables institutions to generate, digitally sign, verify, download, and revoke digital certificates securely.

Each certificate receives:

* SHA-256 Hash
* RSA Digital Signature
* QR Code Verification
* Unique Certificate ID

## ✨ Features

* Admin Login
* User Registration
* Password Reset
* Dashboard with Live Statistics
* Professional PDF Certificate Generation
* QR Code Verification
* Certificate Download
* Issued Certificate Management
* Certificate Revocation
* Tamper Detection

## 🛠️ Technologies Used
